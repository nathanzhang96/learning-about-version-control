# Learning about Version Control

Author: Weizhuo Zhang

Solving merge conflicts takes conscious effort, but I can do it!

What I like the most about version control is that I can track the changes of the project, observe teamates' changes, and restore historical versions if needed. 

What I find the most frustrating about version control is that it's so easy to create conficts during teamwork, and sometimes it requires a huge amount of time to resolve conflicts. Furthermore, it's even more frustrating if my work depends on other teamates' work so I have to wait until they finish their parts before starting my own part.
